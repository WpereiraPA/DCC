# DCC

Package under development for analysis of Central Composite Designs.

## Status

This package is currently in development.

## Objective

Provide tools for:

- model fitting for experimental designs
- ANOVA tables
- effect estimation
- Pareto charts
- response surface plots
- export of analytical reports
